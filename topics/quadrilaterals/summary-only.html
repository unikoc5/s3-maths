① Parallelogram 平行四邊形

  • AB = DC, AD = BC [opp. sides of //gram]
  • ∠A = ∠C, ∠B = ∠D [opp. ∠s of //gram]
  • AE = CE, BE = DE [diags. of //gram]
  • ∠A + ∠B = 180° [int. ∠s, AD // BC]

Diagonals bisect each other but are NOT equal! 對角線互相平分，但不一定相等

② Prove a //gram 證明平行四邊形

  1. Both pairs of opp. sides // [by definition]
  2. Opp. sides equal [opp. sides equal]
  3. Opp. ∠s equal [opp. ∠s equal]
  4. Diags. bisect each other [diags. bisect each other]
  5. One pair of opp. sides equal AND // [2 sides equal and //]
Common route 常見做法：prove △ ≅ first (SSS / SAS / ASA / AAS / RHS) → get equal sides / ∠s [corr. sides, ≅△s] [corr. ∠s, ≅△s] → use one of 1–5.
Equal alt. ∠s / corr. ∠s → lines // [alt. ∠s equal] [corr. ∠s equal]

Way 5: the SAME pair of sides must be equal and //. 必須是同一對邊既相等又平行

③ Rhombus 菱形

  • All 4 sides equal 四邊相等 (also a //gram) [prop. of rhombus]
  • Diags. ⊥ 對角線互相垂直, bisect each other [prop. of rhombus]
  • Diags. bisect the interior ∠s 平分內角 [prop. of rhombus]
  • Area = ½ × AC × BD
Side 17, AC = 30 → AO = 15, BO = √(17² − 15²) = 8

Halve the diagonals first, then Pythagoras! 先把對角線減半再用畢氏定理

④ Rectangle & Square 長方形 & 正方形

  • Rectangle:
  • All ∠s = 90° [prop. of rectangle]
  • Diags. equal and bisect each other → OA = OB = OC = OD [prop. of rectangle]
  • Square: rhombus + rectangle
  • All sides equal [prop. of square]
  • Diags. equal, ⊥ and bisect each other [prop. of square]
  • Diag. makes 45° with each side [prop. of square]

OA = OB → △OAB is isosceles: use base ∠s equal! 用等腰三角形底角相等

⑤ Family Tree 家族樹

Equal diagonals alone ≠ rectangle (isos. trapezium too!). 對角線相等不一定是長方形

⑥ Trapezium 梯形

  • Exactly 1 pair of // sides (the bases 上底、下底)
  • Area = (a + b) × h ÷ 2
  • Isos. trapezium: base ∠s equal, diags. equal
  • Int. ∠s between the // sides add to 180°

h is the ⊥ distance between the bases, not the slant side! 高要垂直於底

⑧ Mid-point Theorem 中點定理

  • 知道兩邊都是中點 → 推出 DE = ½ BC 和 DE // BC
  • DE = ½ BC [mid-pt. thm.]
  • DE // BC [mid-pt. thm.]

Need BOTH mid-points first! 先要兩個中點

⑨ Intercept Theorem 截線定理

  • 知道其中一邊是中點 + 平行 → 推出另一邊也是中點
  • AE = EC [intercept thm.]

Lines must be // first! 先要平行
